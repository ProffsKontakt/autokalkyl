<task type="auto">
  <name>Task 2: Add peak calculation fields to Natagare model</name>
  <files>prisma/schema.prisma</files>
  <action>
Add four new fields to the Natagare model BEFORE the relations section, after isActive field:

```prisma
  // Peak calculation settings (Phase 8 - v1.2 foundation)
  // How to calculate billing peak from consumption data
  peakCalculationMethod String?   @default("SIMPLE_MAX")
  // Discount for night peaks (e.g., 50 = 50% discount for 22:00-06:00 peaks)
  nightDiscountPercent  Decimal?  @db.Decimal(5, 2) @default(50.00)
  // Night hours for peak discount (may differ from day/night tariff hours)
  peakNightStartHour    Int?      @default(22)
  peakNightEndHour      Int?      @default(6)
```

Field explanations:
- `peakCalculationMethod`: String (not enum yet) for flexibility. Default "SIMPLE_MAX" means take max peak directly. Future values: "ELLEVIO_3_PEAK", "VATTENFALL_5_PEAK", etc.
- `nightDiscountPercent`: Decimal for precision. Ellevio uses 50% discount for night peaks.
- `peakNightStartHour/EndHour`: Allow per-natagare night windows (may differ from tariff hours).

All fields nullable with defaults for safe migration of existing natagare records.
  </action>
  <verify>Run `npx prisma validate` - should report no errors</verify>
  <done>Natagare model has peakCalculationMethod, nightDiscountPercent, peakNightStartHour, peakNightEndHour fields</done>
