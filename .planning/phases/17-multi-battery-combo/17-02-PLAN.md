<feature>
  <name>Combo Calculation Aggregation</name>
  <files>src/lib/calculations/combo-calculations.ts, src/lib/calculations/combo-calculations.test.ts</files>
  <behavior>
Combined Results Aggregation:

**Input:** Array of battery selections with quantities, calculation inputs

**Output:** CombinedResults object with:
- totalCapacityKwh: sum of (battery.capacityKwh * quantity) for all batteries
- totalMaxDischargeKw: sum of (battery.maxDischargeKw * quantity) for all batteries
- totalCostExVat: sum of ((totalPriceExVat + installationCost) * quantity) for all batteries
- totalCostIncVat: totalCostExVat * 1.25
- totalCostAfterGronTeknik: totalCostIncVat * (1 - 0.485)
- totalAnnualSavingsSek: sum of per-unit annual savings * quantity
- combinedPaybackYears: totalCostAfterGronTeknik / totalAnnualSavingsSek
- combinedRoi10Year: ((totalAnnualSavings * 10) - totalCostAfterGronTeknik) / totalCostAfterGronTeknik * 100
- combinedRoi15Year: ((totalAnnualSavings * 15) - totalCostAfterGronTeknik) / totalCostAfterGronTeknik * 100
- unitBreakdowns: Array with per-unit and subtotal (unit * quantity) results

**Test Cases:**

1. Single battery, quantity 1:
   - Input: 1x Emaldo 15kWh, price 89900, installation 10000
   - Expected: Same as regular calculation (no change)

2. Single battery, quantity 2:
   - Input: 2x Emaldo 15kWh, price 89900 each, installation 10000 each
   - Expected: totalCapacity = 30.72 kWh, totalCost = 199800 ex VAT

3. Mixed batteries (2 different models):
   - Input: 1x Emaldo 15kWh + 1x Huawei 10kWh
   - Expected: totalCapacity = 25.36 kWh (sum of both)

4. Grid services stacking (COMBO-06):
   - Input: 2x Emaldo 15kWh (both qualify for grid services)
   - Expected: Grid income = 2 * single unit income (stacks per unit)

5. Combined ROI calculation:
   - Input: 2x batteries, known savings/costs
   - Expected: ROI = (total savings * years - total cost) / total cost * 100

6. Edge case - empty array:
   - Input: []
   - Expected: All zeros, no division errors
  </behavior>
  <implementation>
1. Create types for CombinedResults and UnitBreakdown in types.ts or inline

2. Create combo-calculations.ts with:
   - calculateCombinedResults function
   - Use decimal.js for financial precision (already in project)
   - Call calculateBatteryROI for each unique battery config
   - Multiply results by quantity for subtotals
   - Sum subtotals for combined totals
   - Derive payback/ROI from combined totals

3. Handle Gron Teknik on combined total (not per-unit):
   - Apply 48.5% deduction to total investment, not per battery
   - This is correct behavior for subsidy calculations

4. Grid services stacking (COMBO-06):
   - For Emaldo: Each physical unit gets separate enrollment
   - Grid income = number of units * per-unit rate (not capacity-based)
   - For non-Emaldo: Rate per kW applies to total capacity
  </implementation>
</feature>
