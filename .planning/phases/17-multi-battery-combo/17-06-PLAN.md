<task type="checkpoint:human-verify" gate="blocking">
  <what-built>
Complete multi-battery combo feature including:
- Quantity selector per battery in wizard
- Mode toggle (Komboinvestering/Jamfora) in battery step
- Combined results calculation for Komboinvestering mode
- Per-unit breakdown display
- Public share view adapting to combo mode
  </what-built>
  <how-to-verify>
**Test 1: COMBO-01 - Add multiple batteries**
1. Log in as a Closer
2. Start a new calculation wizard
3. Add first battery (e.g., Emaldo 15kWh)
4. Expected: Battery card appears with quantity selector showing "1"
5. Add second different battery (e.g., Huawei 10kWh)
6. Expected: Second battery card appears

**Test 2: COMBO-02 - Mode toggle**
1. With batteries added, verify mode toggle is visible
2. Expected: Toggle between "Komboinvestering" and "Jamfor" visible
3. Default should be "Komboinvestering"
4. Click "Jamfor" - expected: toggle switches, helper text updates

**Test 3: COMBO-03, COMBO-04, COMBO-05 - Komboinvestering combines**
1. Select Komboinvestering mode
2. Add 2x Emaldo 15kWh (set quantity to 2)
3. Set price per unit: 89,900 kr, installation: 10,000 kr each
4. Proceed to results step
5. Expected:
   - Total capacity shows ~30.72 kWh (2 x 15.36)
   - Total cost shows combined (2 x 99,900 = 199,800 ex moms)
   - Single combined ROI and payback shown

**Test 4: COMBO-06 - Grid services stacking**
1. In Komboinvestering results for 2x Emaldo
2. Check Stodtjanster/grid services income
3. Expected: Shows 2x the single-unit rate (stacked per unit)
4. Expand per-unit breakdown to verify stacking calculation

**Test 5: COMBO-07, COMBO-08 - Combined capacity for calculations**
1. In Komboinvestering mode with 2x batteries
2. Check spotpris and peak shaving calculations
3. Expected: Calculations use combined capacity, not single unit

**Test 6: COMBO-09, COMBO-10 - Jamfora mode comparison**
1. Switch to Jamfora mode
2. Add 3 different batteries (max per COMBO-10)
3. Proceed to results
4. Expected: Side-by-side comparison table showing all 3
5. Try adding 4th battery - expected: Should be disabled/blocked

**Test 7: Public share link**
1. In Komboinvestering mode with 2x batteries
2. Complete calculation and save
3. Generate share link
4. Open share link in incognito window
5. Expected:
   - Combined results view (not comparison)
   - No mode toggle visible for prospect
   - Shows total capacity, combined ROI, combined cost

**Test 8: Backward compatibility**
1. Find an existing calculation (pre-phase-17)
2. Open its share link
3. Expected: Should display as before (Jamfora/comparison mode default)
