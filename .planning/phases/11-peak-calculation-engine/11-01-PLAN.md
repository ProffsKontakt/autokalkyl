  <behavior>
    Test cases for peak billing calculations:

    1. Night hour detection (isNightHour):
       - (22, 22, 6) -> true (start of night)
       - (23, 22, 6) -> true (late night)
       - (0, 22, 6) -> true (midnight)
       - (5, 22, 6) -> true (early morning)
       - (6, 22, 6) -> false (day starts)
       - (12, 22, 6) -> false (midday)
       - (21, 22, 6) -> false (evening before night)

    2. Night discount application (applyNightDiscount):
       - (10 kW, true, 50%) -> 5 kW (night peak halved)
       - (10 kW, false, 50%) -> 10 kW (day peak unchanged)
       - (10 kW, true, 0%) -> 10 kW (no discount)

    3. N-peak average calculation (calculateNPeakAverage):
       - dailyPeaks [10, 8, 6, 4, 2], numPeaks=3 -> 8 kW (avg of 10, 8, 6)
       - dailyPeaks with night flags, 50% discount -> correctly weighted
       - All night peaks -> full discount applied before averaging

    4. Simple max calculation (calculateSimpleMax):
       - [10, 8, 6, 4, 2] -> 10 kW
       - Empty array -> 0 kW

    5. Constrained peak shaving:
       - targetReduction 5 kW, batteryMax 10 kW -> 5 kW (not constrained)
       - targetReduction 15 kW, batteryMax 10 kW -> 10 kW (constrained)
       - Returns isConstrained flag and constraintReason

    6. Main calculatePeakBilling function:
       - Inputs: monthly peaks, natagare config, battery constraints
       - Returns: beforePeakKw, afterPeakKw, savings, constraint info
       - Applies correct method based on peakMethod config
  </behavior>
