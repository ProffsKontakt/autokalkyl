```typescript
/**
 * Estimate monthly peak kW from consumption data.
 *
 * Heuristic: Swedish residential peak is typically 2-3x average hourly load.
 * Peak factor varies by heating type (direktverkande has highest peaks).
 */
export function estimateMonthlyPeakKw(
  monthlyKwh: number,
  heatingType: HeatingType
): number
```

Peak factors by heating type (from research):
- DIREKTVERKANDE: 3.5 (sharp peaks when heating kicks in)
- LUFT_LUFT_VP: 2.8 (moderate peaks)
- LUFT_VATTEN_VP: 2.5 (smoother with buffer tank)
- BERGVARME: 2.2 (most stable)
- FJARRVARME: 2.0 (household peaks only)

Formula: avgHourlyKw = monthlyKwh / (30 * 24), then multiply by peak factor.

Also add helper to estimate from annual consumption:
```typescript
export function estimatePeakFromAnnualConsumption(
  annualKwh: number,
  heatingType: HeatingType
): number
```

Use December consumption (highest for electric heating types) as basis.
