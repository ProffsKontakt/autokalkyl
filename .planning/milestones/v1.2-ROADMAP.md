# Milestone v1.2: Realistic Consumption & Peak Tariffs

**Status:** ✅ SHIPPED 2026-02-05
**Phases:** 8-13
**Total Plans:** 19

## Overview

v1.2 replaced the simplified consumption model with realistic Swedish consumption profiles based on heating type and accurate peak tariff calculations using grid operator-specific rules. Added comprehensive analytics with role-based embedded dashboards.

## Milestone Summary

**Decimal Phases:**
None — all phases were planned upfront.

**Key Decisions:**

| Decision | Rationale |
|----------|-----------|
| HeatingType as enum (not string) | Type safety at database and TypeScript level |
| peakCalculationMethod as String | Future-proofs for new grid operators without schema changes |
| Night discount BEFORE sorting | Matches Ellevio billing behavior |
| posthog-node with immediate flush | Required for Vercel serverless (no persistent process) |
| Permanent sidebar over hover dropdown | Better UX for Super Admin navigation |

**Issues Resolved:**
- Spotpris efficiency display bug (90000.2% → 90.2%)
- PostHog events blocked by bot detection
- Hardcoded currentPeakKw values scattered across codebase
- Hover-triggered sidebar confusion

**Issues Deferred:**
- Vattenfall/E.ON peak methods (deadline Jan 2027, placeholders in system)
- No input validation for unrealistic slider combinations
- totalProjectionYears fixed at 10 years

**Technical Debt Incurred:**
- Missing Phase 10 formal verification document (code is complete)
- Database migrations created but need `npx prisma migrate deploy` for production
